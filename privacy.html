日本語

はじめに

Duebell Asset（以下「本アプリ」）は、会社の固定資産について、帳簿の資産と現物をつないで管理し、減価償却の目安・償却資産申告の明細・補助金の処分制限・修繕判定の記録をまとめる Windows 用のデスクトップアプリです。本ポリシーは、本アプリにおける情報の取り扱いを説明します。

本アプリは個人情報を一切収集・送信・共有しません。入力したデータはすべて利用者のデバイス（または利用者が指定したフォルダ）内にのみ保存されます。

1. 収集する情報

  • 本アプリは利用者の個人情報を収集しません。
  • 利用者が入力した次のデータは、利用者のデバイス内のデータベースファイル（既定は「ドキュメント」フォルダの DuebellAsset\duebell_assets.db。Duebell IT と同じ形式。または利用者が指定した共有フォルダなど）にのみ保存されます：
    • 帳簿の資産の情報（資産番号、名称、勘定科目、取得日・事業供用日、取得価額・圧縮記帳額、償却方法・耐用年数、期首帳簿価額、申告の種類・申告先の市町村、除却・売却の記録、備考）と年度確定の値・履歴
    • 現物の情報（管理番号、名称、種類、設置場所、部署、取得日、ラベル印刷・棚卸の記録）と帳簿の資産との紐づけ
    • 償却資産申告の提出状況と提出した明細、補助金（名称・交付日・交付額・処分制限の満了日）、修繕判定の回答と結果
    • 償却率表・金額の基準・勘定科目・仕訳 CSV の列の設定など、利用者が入れた設定
    • 自動・手動のバックアップ（データベースと同じ場所の backup フォルダ）
  • 次回起動時に同じ状態で開く目的で、表示言語・同意した免責事項の版・列の幅・バックアップの控えの保存先が、本アプリの設定ファイル（duebell_assets.ini。Microsoft Store 版ではアプリ専用の領域）に保存されます。
  • Duebell Fleet・Duebell Equip のデータ：利用者が選んだ場合に限り、それらのアプリのデータベース（またはそのバックアップ）から車両・機械の一覧と期限を読み取り専用で読み、本アプリのデータベースに写します。相手のファイルには書き込みません。
  • 共有フォルダで使う場合、同時編集を防ぐためのロックファイルに、編集中の PC 名・Windows のユーザー名・時刻が書かれます。これは同じフォルダを使う利用者に「誰が編集中か」を示すためだけに使われます。
  • これらのファイルが外部へ送信されることはなく、開発者がアクセスすることもできません。

2. 利用目的

上記のデータは、本アプリの機能（台帳の管理、減価償却と申告の計算、期限の判定、記録の出力、表示・設定の復元、共有フォルダでのロック）を提供するためだけに使われます。それ以外の目的には使われません。

3. ネットワーク・オンラインサービス

本アプリはインターネットに接続せずに動作します。テレメトリ・利用解析（アナリティクス）・広告・トラッキング・ユーザーアカウントの仕組みを一切含みません。

Microsoft Store 版では、試用期間とライセンスの確認、および購入を Windows と Microsoft Store の仕組みを通じて行います。これに伴う情報の取り扱いは Microsoft のプライバシーに関する声明に従います。

4. 第三者への提供

本アプリはデータを収集しないため、いかなるデータも第三者へ販売・提供・開示しません。

5. 書き出し機能について

CSV・印刷用 HTML・仕訳 CSV への書き出しは、利用者が明示的に操作したときにのみ実行され、書き出し先は利用者が指定した場所（印刷用 HTML は一時フォルダ）です。本アプリが自動で送信することはありません。

6. データの保存期間と削除

データは、利用者が削除するまで保存されます。本アプリをアンインストールしても、業務データを失わないようデータベースとバックアップ（「ドキュメント」フォルダの DuebellAsset）は残ります。不要になったら利用者がフォルダごと削除してください。設定ファイルはアンインストール時に削除されます。

7. セキュリティ

データは利用者のデバイスまたは利用者が指定したフォルダにのみ保存されるため、その安全性は利用者のデバイス・ネットワークのセキュリティ対策に依存します。

8. 子どものプライバシー

本アプリは、子どもを含むいかなる利用者からも情報を収集しません。

9. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。最新版はこのページに掲載します。

10. お問い合わせ

English

Introduction

Duebell Asset ("the App") is a Windows desktop application that keeps a company's fixed assets with the book asset and the physical item linked, and helps with the estimated depreciation, the depreciable asset tax return, subsidy restrictions and repair-or-improvement decisions. This policy explains how the App handles information.

The App does not collect, transmit, or share any personal data. Everything you enter is stored only on your device (or in a folder you choose).

1. Information we collect

  • The App does not collect any personal information.
  • The data you enter is stored in a database file on your device (by default DuebellAsset\duebell_assets.db in your Documents folder, the same format as Duebell IT's, or another location you choose, such as a shared folder):
    • Book assets (number, name, account, acquisition and in-service dates, cost and compression, method and useful life, opening book value, tax return kind and municipality, disposals, notes) and year closings with their history
    • Physical items (asset number, name, type, location, department, acquisition date, label printing and stocktakes) and their links to book assets
    • Tax return states and the lines filed, subsidies (name, grant date, amount, end of the restriction), repair-or-improvement answers and results
    • Your settings: the rate table, amount limits, accounts, the columns of the journal CSV
    • Automatic and manual backups (a backup folder next to the database)
  • To open the App the way you left it, the display language, the version of the accepted disclaimer, column widths and the second backup folder are stored in the App's settings file (duebell_assets.ini; in the Microsoft Store version, in the App's own storage).
  • Duebell Fleet and Duebell Equip data: only when you choose them, the vehicles, machines and due dates are read (read-only) from those applications' databases (or their backups) and copied into the App's database. Their files are never written.
  • When the database is in a shared folder, a lock file records the editing PC's name, the Windows user name and the time, to prevent simultaneous editing. It is used only to show other users of the same folder who is editing.
  • These files never leave your device, and the developer cannot access them.

2. How we use information

The data is used only to provide the App's functionality (keeping the ledger, calculating depreciation and the tax return, judging due dates, exporting records, restoring the display and settings, and locking a shared database). It is not used for any other purpose.

3. Network and online services

The App works without an internet connection. It contains no telemetry, analytics, advertising, tracking or user accounts.

In the Microsoft Store version, the trial period, the licence check and purchases are handled by Windows and the Microsoft Store; the Microsoft Privacy Statement applies.

4. Sharing with third parties

Because the App does not collect data, it does not sell, share or disclose any data to third parties.

5. Export features

Export to CSV, printable HTML and journal CSV runs only when you ask for it, and writes to the location you choose (printable HTML goes to the temporary folder). The App never transmits anything.

6. Retention and deletion

Data is kept until you delete it. Uninstalling the App leaves the database and backups (the DuebellAsset folder in Documents) in place so that business data is not lost; delete the folder when you no longer need it. The settings file is removed with the App.

7. Security

Data is stored only on your device or in a folder you choose, so its security depends on the security measures of your device and network.

8. Children's privacy

The App does not collect information from anyone, including children.

9. Changes to this policy

This policy may be updated as needed. The latest version is always published on this page.

10. Contact
